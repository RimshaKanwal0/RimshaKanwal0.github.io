# Rimsha Kanwal — Portfolio

Personal portfolio of Rimsha Kanwal, AI Engineer based in Lahore.

**Live:** https://rimshakanwal0.github.io

Plain HTML, CSS and JavaScript (no framework), so it loads fast.


## Update content
- `data.js`: experience, certificates, skills, projects and social links
- `index.html`: name, hero text, about text, email
- `assets/`: photo, project images, icons

Push to `main` and GitHub Pages redeploys automatically.
